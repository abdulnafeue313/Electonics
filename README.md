# My Business Website

Generated by My AI Agent.

## Features
- Product catalog with relevant pictures
- Cart and checkout
- Complete customer delivery details
- Orders and My Orders
- Admin order dashboard and status
- Service requests
- Contact messages
- Email signup and verification
- Google login configuration
- Facebook login configuration
- Password hashing
- SQLite automatic schema migration
- Reviews

## Run
```powershell
python -m pip install -r requirements.txt
python app.py
```

http://127.0.0.1:5000/auth/google/callback
